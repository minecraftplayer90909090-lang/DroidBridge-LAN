# Package contents

This 0.4.0 package contains:

- GitHub/IntelliJ Gradle project for DroidBridge LAN.
- Readable DroidBridge compatibility source.
- No bundled or modified e4mc JAR.
- Fabric metadata declaring e4mc as a required external dependency.
- Android ARM64 `libnetty_quiche.so`, pinned by SHA-256.
- Exact Netty QUIC `0.0.74.Final.e4mc.1` source snapshot used for the native ABI.
- GitHub Actions for the Java mod build and Android native rebuild.
- Project and native third-party license/notice files.
- CurseForge description, upload fields, release checklist, and GitHub release notes.
- Original DroidBridge LAN icon/branding.
