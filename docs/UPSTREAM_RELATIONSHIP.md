# Relationship to e4mc

DroidBridge LAN is an **independent compatibility add-on** for the official e4mc mod. It is not an official e4mc port and should not be presented as one.

## Packaging policy

DroidBridge LAN 0.4.0 does not bundle a modified e4mc JAR and does not ship `link.e4mc.*` classes. Users install e4mc separately as a required dependency.

DroidBridge LAN provides Android-specific native/runtime compatibility around the installed upstream mod. e4mc continues to own the public tunnel and Minecraft integration.

## Branding

Use DroidBridge LAN branding for this project. Credit and link e4mc clearly, but do not reuse the e4mc logo as the DroidBridge LAN project icon or imply upstream endorsement.

## Support routing

DroidBridge/Android compatibility issues should be reported to DroidBridge LAN. General e4mc behavior should be reproduced without DroidBridge LAN before being reported upstream.
