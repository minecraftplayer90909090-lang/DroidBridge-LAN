# Contributing

Keep DroidBridge-specific changes isolated and documented. Do not remove upstream copyright/license notices.

For changes touching e4mc or Netty-Quiche compatibility:

- state the exact upstream version/ABI,
- describe why the patch is Android-specific,
- preserve the upstream license header,
- add a prominent modification notice when changing Apache-licensed files,
- include a real remote-network test result before marking a target supported.
