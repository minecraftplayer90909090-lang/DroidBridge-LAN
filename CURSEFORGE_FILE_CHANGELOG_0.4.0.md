## DroidBridge LAN 0.4.0

- e4mc is now a required separate dependency instead of being bundled.
- Added early Android Netty-Quiche native preload for stock e4mc.
- Kept Android Dialtone/iroh compatibility handling runtime-only.
- Preserved automatic recovery from truncated e4mc configuration files.
- No e4mc classes are included in the DroidBridge LAN JAR.
